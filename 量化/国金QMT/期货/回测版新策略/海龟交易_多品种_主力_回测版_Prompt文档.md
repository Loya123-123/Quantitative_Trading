# 海龟交易策略 - 多品种期货主力合约（回测版）

## 1. 策略概述

**策略名称**: 海龟交易_多品种_主力_回测版
**交易平台**: QMT（国金证券）
**版本类型**: 回测版
**交易品种**: 期货多品种（支持沥青、焦煤、沪铝等）
**合约选择**: 主力合约（自动切换当前市场主力合约）
**策略类型**: 趋势跟随型突破策略

### 核心逻辑

本策略基于经典的海龟交易法则改编，适用于期货多品种回测：

- **ATR指标**: 使用10日ATR平均值作为市场波动性的衡量标准
- **入场信号**: 价格突破近10日最高点做多，跌破近10日最低点做空
- **出场信号**: 价格跌破近4日最低点或达到止盈目标价时平仓
- **止损机制**: 基于入场价±N倍ATR进行止损

### 与实盘版区别

- 移除实盘下单API调用（passorder, cancel等）
- 添加模拟交易执行逻辑
- 使用虚拟账户和资金进行回测
- 不发送飞书通知（仅记录日志）
- 跳过交易时间检查，使用日线数据进行回测

## 2. 策略参数

### 2.1 核心参数

| 参数名称 | 默认值 | 说明 |
|---------|-------|------|
| `entry_window` | 10 | 入场通道周期（计算N日高低点） |
| `exit_window` | 4 | 出场通道周期（止损通道） |
| `atr_window` | 10 | ATR计算周期 |
| `stop_profit_ratio` | 0.2 | 止盈比例（20%） |
| `stop_loss_multiplier` | 1 | 止损ATR倍数 |
| `position_limit` | 5 | 最大持仓品种数 |
| `near_expiry_days` | 30 | 临近到期天数（低于此天数不建仓） |
| `capital_rate` | 0.1 | 资金使用率（10%） |
| `initial_capital` | 100000 | 回测初始资金（10万） |

### 2.2 品种配置

```python
ContextInfo.stock_codes_dict = {
    "FG": {"code": "FG00", "market": "ZF", "size": 12},  # 沥青
```

## 3. 入场规则

### 3.1 做多入场（Long Entry）

**触发条件**:
- 当前无多头仓位
- 合约距离到期日 > 30天
- 当前持仓数 < 最大持仓限制
- **收盘价 >= 近10日最高价**

**信号**: `(1, 1)` - 买入开多仓

### 3.2 做空入场（Short Entry）

**触发条件**:
- 当前无空头仓位
- 合约距离到期日 > 30天
- 当前持仓数 < 最大持仓限制
- **收盘价 <= 近10日最低价**

**信号**: `(1, -1)` - 卖出开空仓

---

## 4. 出场规则

### 4.1 多头出场（Long Exit）

**止盈条件**:
- 价格 < 近4日最低价 **且** 价格 < 最高点 - (最高点 - 入场价) × 20%

**止损条件**:
- 价格 < 入场价 - N × ATR

**信号**: `(-1, 1)` - 平多头仓

### 4.2 空头出场（Short Exit）

**止盈条件**:
- 价格 > 近4日最高价 **且** 价格 > 最低点 + (入场价 - 最低价) × 20%

**止损条件**:
- 价格 > 入场价 + N × ATR

**信号**: `(-1, -1)` - 平空头仓

## 5. 核心函数

### 5.1 `init(ContextInfo)`

初始化函数，执行以下操作：
- 设置虚拟账户ID
- 配置交易品种
- 初始化全局变量（持仓状态、ATR值、止盈止损价格等）
- 设置定时任务（使用日线周期执行）
- 初始化回测资金

### 5.2 `run_time_handlebar(ContextInfo)`

主循环函数，每根K线执行一次：
- 检查是否为周末（是则跳过）
- 获取当前主力合约
- 获取账户信息
- 遍历每个合约执行交易逻辑

**注意**: 回测版跳过交易时间检查

### 5.3 `is_weekend()`

判断当前是否为周末：
- 获取当前日期时间
- 判断是否为周六（weekday=5）或周日（weekday=6）
- 若是周末，返回`True`并打印日志 `"[时间判断] 当前是周末，退出程序"`
- 若非周末，返回`False`

### 5.4 `get_price_data(ContextInfo)`

获取历史价格数据：
- 获取N+5根历史K线
- 返回完整的OHLC数据

### 5.5 `get_backtest_account_info()`

获取回测账户信息（模拟）：
- 获取可用资金
- 从模拟持仓中获取持仓信息
- 更新持仓状态变量

### 5.6 `calculate_atr(stock_code, data, window)`

计算ATR（N值）：
```
TR = MAX(High - Low, |High - Close_prev|, |Low - Close_prev|)
ATR = MA(TR, N)
```

### 5.7 `generate_signal(ContextInfo, price_data)`

生成交易信号：
- 计算入场通道（上轨/下轨）
- 计算出场通道
- 判断是否触发入场/出场条件

### 5.8 `execute_trade(ContextInfo, signal, price_data)`

执行交易（回测版 - 模拟成交）：
- 根据信号类型执行开仓/平仓
- 模拟资金扣除和归还
- 记录持仓信息（开仓日期、开仓价格等）
- 更新模拟账户资金

## 8. 回测执行说明

1. **数据周期**: 使用日线（1d）数据进行回测
2. **初始资金**: 10万元人民币
3. **保证金**: 假设10%保证金比例
4. **滑点**: 暂不考虑
5. **手续费**: 暂不考虑

## 10. 注意事项

1. 代码使用GBK编码
2. 回测版本不发送飞书通知
3. 历史数据不足时不执行交易
4. 主力合约会自动切换，无需手动更换合约代码
5. 回测结果仅供参考，实际交易可能存在差异
