# 网格交易实盘策略 - Prompt文档 (v3 - 布林带入场与双重止损版)

## 策略概述

本策略结合了**布林带择时入场**与**双向等比网格算法**。策略在价格低位（触及布林下轨）时启动，利用网格捕捉反弹与震荡收益，并辅以严密的 ATR 动态止损与比例止损机制。

**核心逻辑**：
- **择时入场**：仅在 **当前价格 <= 布林带下轨 (20, 2)** 时启动该品种的网格交易。
- **等比网格**：成交后按 1% 比例进行对冲布单。
- **双重止损**：
    - 比例止损：全仓位亏损超过 10%。
    - 动态止损：价格低于 “持仓均价 - 2.5 * ATR”。
- **实盘校验**：通过持仓成本校准水位，结合本地 JSON 进行订单追踪。

## 核心参数配置

| 参数名 | 默认值 | 说明 |
| :--- | :--- | :--- |
| `bb_window` | 20 | 布林带计算周期 |
| `bb_std_dev` | 2 | 布林带标准差倍数 |
| `grid_ratio` | 0.01 | 等比网格间距 (1%) |
| `stop_loss_ratio` | 0.10 | 最大持仓亏损比例 (10%) |
| `atr_stop_multiplier` | 2.5 | ATR 动态止损倍数 |
| `max_lots` | 10 | 单品种单边最大持仓手数 |
| `work_dir` | C:\合约选品\ | 本地配置文件存放路径 |

## 策略运行流程

### 1. 初始化与选品
- 定时读取品种池 Excel，筛选出趋势或效率排名前列的活跃合约。
- 初始化每个品种的状态：`status: 'WAITING'` (等待布林带信号)。

### 2. 信号监控 (Entry)
- 每个周期计算标的的布林带。
- 如果 `price <= lower_band` 且当前无持仓：
    - **启动交易**：执行第一笔市价/限价买入。
    - **转换状态**：`status: 'GRIDDING'`。
    - **建立网格**：以成交价为 Base Price，挂出后续的等比买卖单。

### 3. 网格维护与补单
- **成交校验**：通过 `get_account_info` 获取实际持仓成本。
- **对冲逻辑**：
    - 买单成交：在 `成交价 * (1 + 1%)` 处挂卖平。
    - 卖单成交：在 `成交价 * (1 - 1%)` 处挂买平。

### 4. 实时止损 (Risk Content)
每周期检查持仓：
- **条件 A**：`(持仓市值 - 持仓成本) / 持仓成本 < -10%`。
- **条件 B**：`当前价 < 持仓均价 - 2.5 * ATR`。
- **动作**：若任一满足，立即撤销所有挂单，市价平仓该品种，并进入 `status: 'STOPPED'` 或重新等待信号。

## 异常处理与持久化

- **状态记录**：`grid_status.json` 中记录当前基准价、已挂单 ID、止损基准等信息。
- **通知系统**：订单成交、止损触发、入场成功均通过飞书 Webhook 实时推送。

---

## 注意事项

1. **GBK 编码**：确保文件保存为 GBK 格式以兼容 QMT。
2. **持仓同步**：由于 QMT 委托回报可能有延迟，核心逻辑必须以 `ContextInfo.get_trade_detail_data` 的 `POSITION` 数据为准。
