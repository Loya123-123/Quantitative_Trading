# 海龟交易策略 - 多品种期货主力合约

## 1. 策略概述

**策略名称**: 海龟交易_多品种_主力
**交易平台**: QMT（国金证券）
**交易品种**: 期货多品种（支持沥青、焦煤、沪铝等）
**合约选择**: 主力合约（自动切换当前市场主力合约）
**策略类型**: 趋势跟随型突破策略

### 核心逻辑

本策略基于经典的海龟交易法则改编，适用于期货多品种交易：

- **ATR指标**: 使用10日ATR平均值作为市场波动性的衡量标准
- **入场信号**: 价格突破近10日最高点做多，跌破近10日最低点做空
- **出场信号**: 价格跌破近4日最低点或达到止盈目标价时平仓
- **止损机制**: 基于入场价±N倍ATR进行止损

---

## 2. 策略参数

### 2.1 核心参数

| 参数名称 | 默认值 | 说明 |
|---------|-------|------|
| `entry_window` | 10 | 入场通道周期（计算N日高低点） |
| `exit_window` | 4 | 出场通道周期（止损通道） |
| `atr_window` | 10 | ATR计算周期 |
| `stop_profit_ratio` | 0.2 | 止盈比例（20%） |
| `stop_loss_multiplier` | 1 | 止损ATR倍数 |
| `position_limit` | 5 | 最大持仓品种数 |
| `near_expiry_days` | 30 | 临近到期天数（低于此天数不建仓） |
| `capital_rate` | 0.1 | 资金使用率（10%） |

### 2.2 品种配置

```python
ContextInfo.stock_codes_dict = {
    "FG": {"code": "FG00", "market": "ZF", "size": 12},  # 沥青
    "jm": {"code": "jm00", "market": "DF", "size": 3},   # 焦煤
    "ao": {"code": "ao00", "market": "SF", "size": 5},  # 沪铝
}
```

- `code`: 合约代码
- `market`: 交易所标识（ZF=郑商所，DF=大商所，SF=上期所）
- `size`: 交易手数

## 3. 入场规则

### 3.1 做多入场（Long Entry）

**触发条件**:
- 当前无多头仓位
- 合约距离到期日 > 30天
- 当前持仓数 < 最大持仓限制
- **收盘价 >= 近10日最高价**

**信号**: `(1, 1)` - 买入开多仓

### 3.2 做空入场（Short Entry）

**触发条件**:
- 当前无空头仓位
- 合约距离到期日 > 30天
- 当前持仓数 < 最大持仓限制
- **收盘价 <= 近10日最低价**

**信号**: `(1, -1)` - 卖出开空仓

---

## 4. 出场规则

### 4.1 多头出场（Long Exit）

**止盈条件**:
- 价格 < 近4日最低价 **且** 价格 < 最高点 - (最高点 - 入场价) × 20%

**止损条件**:
- 价格 < 入场价 - N × ATR

**信号**: `(-1, 1)` - 平多头仓

### 4.2 空头出场（Short Exit）

**止盈条件**:
- 价格 > 近4日最高价 **且** 价格 > 最低点 + (入场价 - 最低点) × 20%

**止损条件**:
- 价格 > 入场价 + N × ATR

**信号**: `(-1, -1)` - 平空头仓

---

## 5. 核心函数

### 5.1 `init(ContextInfo)`

初始化函数，执行以下操作：
- 设置账户ID
- 配置交易品种
- 初始化全局变量（持仓状态、ATR值、止盈止损价格等）
- 设置定时任务（每3秒执行一次）

### 5.2 `run_time_handlebar(ContextInfo)`

主循环函数，每根K线执行一次：
- 检查是否为周末（是则跳过）
- 检查交易时间
- 获取当前主力合约
- 获取账户信息
- 遍历每个合约执行交易逻辑

### 5.3 `is_weekend()`

判断当前是否为周末：
- 获取当前日期时间
- 判断是否为周六（weekday=5）或周日（weekday=6）
- 若是周末，返回`True`并打印日志 `"[时间判断] 当前是周末，退出程序"`
- 若非周末，返回`False`

### 5.4 `get_price_data(ContextInfo)`

获取历史价格数据：
- 获取N+5根历史K线
- 获取当日实时数据
- 合并为完整的OHLC数据

### 5.5 `get_account_info(ContextInfo)`

获取账户信息：
- 获取账户可用资金、总权益
- 获取当前持仓信息（合约代码、持仓方向、持仓量、持仓成本、开仓日期）
- 获取未成交委托信息，并自动撤销未成交委托
- 更新持仓状态变量

### 5.6 `calculate_atr(stock_code, data, window)`

计算ATR（N值）：
```
TR = MAX(High - Low, |High - Close_prev|, |Low - Close_prev|)
ATR = MA(TR, N)
```

### 5.7 `generate_signal(ContextInfo, price_data)`

生成交易信号：
- 计算入场通道（上轨/下轨）
- 计算出场通道
- 判断是否触发入场/出场条件

### 5.8 `execute_trade(ContextInfo, signal, price_data)`

执行交易：
- 根据信号类型执行开仓/平仓
- 记录持仓信息（开仓日期、开仓价格等）
- 发送飞书通知

## 7. 交易时间控制

策略仅在交易时段执行：
- 夜盘: 21:00 - 24:00（部分品种至次日2:30）
- 日盘: 9:00 - 11:30, 13:30 - 15:00

**注意**: 09:00开盘第一根K线不执行交易

---

## 8. 风险控制

1. **持仓限制**: 最多同时持有5个品种
2. **单品种手数固定**: 每个品种配置固定交易手数
3. **临近到期不建仓**: 距到期日小于30天时不新建仓位
4. **ATR动态止损**: 根据市场波动性自动调整止损幅度
5. **止盈机制**: 达到20%收益目标时触发止盈

## 10. 飞书通知

策略关键事件会发送飞书消息通知：
- 交易委托执行结果
- 异常错误信息
- 账户信息获取失败

---

## 11. 注意事项

1. 代码使用GBK编码
2. 账户ID通过外部变量`account`传入
3. 历史数据不足时不执行交易
4. 未成交的委托会被排除在交易名单外
5. 主力合约会自动切换，无需手动更换合约代码
