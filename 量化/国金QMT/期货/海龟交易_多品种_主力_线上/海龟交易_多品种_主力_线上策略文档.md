# 海龟交易_多品种_主力_线上策略文档

## 策略概述

这是一个基于经典海龟交易法则的多品种期货自动化交易策略，运行在国金QMT平台上。该策略采用趋势跟踪的方法，通过ATR(平均真实波幅)指标进行风险管理和仓位控制。

## 核心交易逻辑

### 1. 入场信号（开仓条件）

#### 多头入场（做多）
- 当前收盘价 > 前10日收盘价最高点时，即价格突破前10日高点，执行做多操作

#### 空头入场（做空）
- 当前收盘价 < 前10日收盘价最低点时，即价格突破前10日低点，执行做空操作

### 2. 出场信号（平仓条件）

#### 多头出场
满足以下任一条件时平多仓：
1. **止盈条件1**：从第二个K线开始，当价格 < 前4日收盘价最低点时，且价格 < 最高价 - (最高价 - 入场价) * 20% 时，在最高价指向见顶时达到极值时，执行平仓
2. **止损条件1**：从第二个K线开始，当价格 < 入场价 - N * ATR时，执行平仓

#### 空头出场
满足以下任一条件时平空仓：
1. **止盈条件2**：从第二个K线开始，当价格 > 前4日收盘价最高点时，且价格 > 最低价 + (入场价 - 最低价) * 20% 时，在最低价指向见底时达到极值时，执行平仓
2. **止损条件2**：从第二个K线开始，当价格 > 入场价 + N * ATR时，执行平仓

## 仓位管理

### 资金分配原则
- 总资金 = 100000元
- 多品种分散投资，每品种最多投入20000元
- 单合约按1手计算，每手价值约10000元
- 采用逐步加仓策略，不影响最后的可开数量

### 持仓限制
- 最大持仓合约数：4个
- 合约到期前30天内不新开仓
- 当前持仓达到上限时暂停新交易

## 时间控制

### 交易时段判断
策略只在以下时间段执行：
- 0:00-2:30（夜盘）
- 9:00-11:30（上午盘）
- 13:30-15:00（下午盘）
- 21:00-24:00（夜盘）

### 特殊时间处理
- 9:00整点的第一个K线不参与交易
- 根据当前小时判断期货开盘时间，确保获取正确的起始时间

## 技术指标计算

### ATR(N值)计算
```
TR = MAX(High-Low, ABS(High-Close_prev), ABS(Low-Close_prev))
ATR = MA(TR, N)
```

### 通道计算
- 上轨：前N日收盘价最高点
- 下轨：前N日收盘价最低点
- 止盈通道：前4日收盘价最低点/最高点

### 3. 数据获取与处理

- 处理夜盘和日盘数据的衔接

### 4. 信号生成与执行
- 计算ATR值
- 生成交易信号
- 执行相应的买卖操作

## 防止重复下单机制

### 问题背景
策略定时3秒执行一次，由于期货成交存在延迟，经常出现以下问题：
- 委托状态已变成"已成"（56），但持仓记录里还没有
- 下一次循环检查时发现没有持仓，再次下单导致手数翻倍

### 解决方案：冷却期机制

#### 核心逻辑
1. **下单记录**：开仓下单成功后，将合约、做多/做空、手数、下单时间记录到 `g.last_open_order`
2. **冷却过滤**：每次执行前调用 `filter_cooling_contracts()` 过滤冷却期内的合约
3. **双重核查**：
   - 核查点1：上一次下单时间距离现在时间差距 < `g.order_cooldown_seconds`（默认10秒）
   - 核查点2：持仓记录 `g.position_code` 能查到该合约的信息

#### 过滤规则
| 时间差距 | 持仓状态 | 处理方式 |
|---------|---------|---------|
| < 10秒 | 持仓未确认 | 从待处理列表中剔除 |
| < 10秒 | 持仓已确认 | 清理记录，正常处理 |
| >= 10秒 | - | 清理记录，释放冷却 |

#### 函数说明

**filter_cooling_contracts()**
- 位置：`run_time_handlebar` 函数中，在获取账户信息之后、遍历合约列表之前调用
- 功能：过滤冷却期内的合约，并清理已过冷却期的记录
- 返回：过滤后的合约列表

## 注意事项

1. **数据质量**：确保获取的历史数据完整性和准确性
2. **网络稳定性**：保持与QMT平台的稳定连接
3. **时间同步**：确保系统时间与交易所时间同步
4. **资金安全**：合理设置风险参数，避免过度交易
5. **监控维护**：定期检查策略运行状态和日志信息

## 策略优势

1. **经典有效**：基于经过时间验证的海龟交易法则
2. **风险可控**：完善的止损止盈机制
3. **分散投资**：多品种配置降低单一风险
4. **自动化执行**：减少人为情绪干扰
5. **实时监控**：完善的日志和消息推送系统

## 策略局限性

1. **趋势依赖**：主要适用于趋势性市场
2. **震荡市表现**：在震荡市场中可能频繁止损
3. **参数敏感**：参数设置对策略表现影响较大
4. **滑点成本**：实际执行价格可能与信号价格存在偏差
