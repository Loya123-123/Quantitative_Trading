# A股网格交易实盘策略 - Prompt文档 (T+1 单边版)

## 策略概述

本策略专为 **A 股市场** 设计，针对指数 ETF（如 510100.SH 和 510310.SH）执行**单边做多网格**。通过布林带择时入场，结合 1% 等比买入与卖出逻辑，实现低位潜伏与波段盈利。

**核心逻辑**：
- **交易品种**：510100.SH (上证50等权ETF), 510310.SH (沪深300ETF)。
- **T+1 机制**：充分考虑 A 股 T+1 限制，当日成交的买单将记录在案，待次日“可用持仓”更新后方可执行对应的卖出网格。
- **布林择入**：仅在价格触及 **布林下轨 (20, 2)** 时启动。
- **双重止损**：全仓亏损 10% 或 价格跌破 “均价 - 2.5 * ATR”。

---

## 核心参数配置

| 参数名 | 默认值 | 说明 |
| :--- | :--- | :--- |
| `stock_list` | ['510100.SH', '510310.SH'] | 交易标的列表 |
| `grid_ratio` | 0.01 | 等比网格比例 (1%) |
| `grid_lot_size` | 100 | 最小下单单位 (100股) |
| `stop_loss_ratio` | 0.10 | 10% 比例止损 |
| `atr_multiplier` | 2.5 | ATR 动态止损倍数 |
| `max_positions` | N | 后续通过账户资产动态计算的手数上限 |

---

## T+1 网格流转流程

1.  **触轨买入**：价格触及布林下轨 -> 买入 N 股 (100 整数倍)。
2.  **当日锁定**：成交后，记录该笔交易在 JSON。此时“已持仓”增加，但“可用持仓”不变。
3.  **次日挂单**：
    - 每个交易日早盘启动时，同步可用持仓。
    - 对已买入且“可用”的持仓，在 `买入成本 * (1 + 1%)` 处挂出限价卖单。
4.  **震荡补单**：
    - 若价格继续下跌 1%，继续买入并累积。
    - 若价格上涨触及卖点且有可用仓位，则卖出获利。

---

## 风险管理

- **最小跳动单位**：适配 A 股最小报价跳动（通常 0.001）。
- **持仓封顶**：单只 ETF 持仓总额不超过预设比例，防止重仓单一指数。
- **紧急撤单**：若触发 10% 或 2.5*ATR 止损，立即撤销所有未成交买单，并在有可用持仓时市价出局。

---

## 异常处理

- **除权除息**：ETF 虽无常见除权，但若发生价格跳空，网格 base_price 将根据当日均价重新对齐。
- **持久化**：`C:\合约选品\stock_grid_status.json` 记录所有未卖出的买单层级，确保重启后逻辑连续。

---

## 注意事项

1. **GBK 编码**：策略文件必须保持 GBK 编码。
2. **opType**：买入为 0，卖出为 1。
3. **可用性检查**：每一笔卖单执行前必须调用 `passorder` 前检查 `m_nCanUseVolume`。
