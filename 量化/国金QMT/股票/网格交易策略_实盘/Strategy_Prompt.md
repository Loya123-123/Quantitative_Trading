# 策略 Prompt：保守型布林动态网格策略 (QMT 期货实盘版)

## 1. 策略哲学与目标
- **核心逻辑**：均值回归（Mean Reversion）。利用统计学极值（布林下轨）入场，捕捉超跌反弹。
- **风险偏好**：保守型。宁愿空仓等待，不追高，严格限制回撤。
- **适用行情**：宽幅震荡行情、慢牛回踩行情；通过过滤机制规避单边暴跌。

## 2. 技术指标配置 (Parameters)
- **布林带 (Bollinger Bands)**：周期=20，标准差=2。
    - 中轨 (Mid)：作为价值中枢和止盈观察起始点。
    - 下轨 (Lower)：作为入场警戒线。
- **ATR (Average True Range)**：周期=14。
    - 用于计算动态止损位和止盈保护垫，适应不同品种的波动率。
- **均线 (MA)**：周期=60。
    - 趋势过滤器：MA60 斜率 >= 0 时方可入场。

## 3. 入场阶段逻辑 (Entry Logic)
- **触发信号**：当前价格 $\le$ 布林下轨。
- **条件过滤**：MA60 斜率平缓或向上（拒绝参与单边加速下行行情）。
- **资金分配 (2/8原则)**：
    - **底仓 (20%)**：入场信号触发时立即以市价/极速限价单买入。
    - **网格仓 (80%)**：在下轨至中轨之间布置 3-5 档买单。
- **动态调整**：若价格未成交且布林下轨继续下移（变动幅度 > 0.5%），程序需同步平移网格挂单。

## 4. 止盈阶段逻辑 (Take Profit - 利润保留法)
- **激活观察**：当价格回升触及 **布林中轨** 时，进入 `TRAILING`（跟踪止盈）状态。
- **动态止盈公式**：
    - 记录进入观察期后的最高价 $MaxPrice$。
    - 计算利润回撤垫子：$Buffer_{profit} = (MaxPrice - EntryPrice) \times 20\%$。
    - 计算噪音保护空间：$Buffer_{min} = 0.5 \times ATR$。
    - **最终触发价**：$TriggerPrice = MaxPrice - \max(Buffer_{profit}, Buffer_{min})$。
- **执行**：价格跌破 $TriggerPrice$ 时全仓平仓。

## 5. 风控管理 (Risk Control)
- **硬止损**：当前价格 $<$ $EntryPrice - 2.5 \times ATR$。一旦触碰，无条件清仓。
- **账户熔断**：若单笔策略最大回撤超过总资金的 5%，停止该品种交易。
- **QMT 实盘适配**：
    - 需处理 API 频率限制，避免在布林线微幅波动时频繁撤单重挂。
    - 需处理期货品种的跳空缺口（Gap）对 ATR 的影响。

## 6. 开发状态机设计 (State Machine)
- `STATE_IDLE`: 扫描行情，等待下轨信号。
- `STATE_BUYING`: 信号触发，执行底仓买入并布置动态网格。
- `STATE_HOLDING`: 持仓中，监控硬止损位，等待价格到达中轨。
- `STATE_TRAILING`: 到达中轨，根据“利润回撤 20%”公式实时更新止盈触发价。
