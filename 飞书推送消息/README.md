# 策略日志监控脚本

## 功能说明

这是一个用于监控期货策略运行状态的日志检查脚本，主要功能包括：

1. 检查策略日志文件是否存在
2. 验证日志中是否包含指定的期货账户ID
3. 检测日志中是否存在异常信息
4. 通过飞书机器人推送监控结果（中文消息）

## 检查逻辑

### 1. 日志文件存在性检查
- 在 `/Users/jianzhong/ProjectCode/Quantitative_Trading/log` 目录下查找 `datalog-*.log` 格式的日志文件（兼容旧格式）及 `datalog-<account_id>-*.log` 格式的新日志文件
- 选择修改时间最新的日志文件进行检查
- 验证文件时间是否在最近7天内
- 如果日志文件不存在，推送中文预警消息："警告: 策略日志文件不存在！策略可能未运行。时间: ..."

### 2. 账户ID检查
- 检查日志文件的前15行
- 验证是否包含期货账户ID: `809212961`
- 如果找不到该ID，则认为策略运行异常
- 如果未找到账户ID，推送中文预警消息："警告: 在日志中未找到账户ID 809212961，策略可能运行异常！时间: ..."

### 3. 异常信息检查
- 检查日志文件的最后200行
- 寻找最近一次完整的策略执行过程（从"[处理函数] 开始执行handlebar函数"到"[处理函数] handlebar函数执行完成"）
- 检查该执行过程中是否包含"异常处理"关键字
- 如果在完整执行过程中未找到异常，也会检查整个最后200 行是否有异常
- 如果发现异常，推送中文预警消息："警报: 在策略日志中发现异常！\n时间: ...\n日志文件: ...\n异常内容: ..."
- 如果一切正常，推送中文正常消息："策略运行正常 时间: ..."

## 推送消息类型

- **日志文件不存在**：推送中文预警信息 "警告: 策略日志文件不存在！策略可能未运行。时间: ..."
- **账户ID未找到**：推送中文预警信息 "警告: 在日志中未找到账户ID 809212961，策略可能运行异常！时间: ..."
- **发现异常记录**：推送中文预警信息 "警报: 在策略日志中发现异常！\n时间: ...\n日志文件: ...\n异常内容: ..."
- **一切正常**：推送中文正常通知 "策略运行正常 时间: ..."

## 配置信息

脚本使用 `/Users/jianzhong/ProjectCode/Quantitative_Trading/飞书推送消息/配置信息.json` 中的飞书机器人配置进行消息推送。

## 使用方法

直接运行脚本：
```bash
python check_strategy_log.py
```

## 注意事项

- 脚本需要网络连接以发送飞书消息
- 如果发送飞书消息失败，相关错误信息会在控制台输出（中文）
- 脚本会尝试多种编码（UTF-8、GBK、GB2312、Latin-1）来读取日志文件
- 时间判断以系统时间为基准
- 所有输出和推送消息均为中文
